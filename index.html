Why in-browser matters

Config files carry secrets and exports carry customer data. Most “free online converters” quietly ship both to a server. FileKiln has no upload endpoint to trust, because there is no upload.

Static pages

Each tool is a plain page with its logic in readable JavaScript. Nothing is minified past inspection.

Real parsers

YAML runs on js-yaml, CSV follows RFC 4180 quoting. Errors come back with line numbers, not shrugs.

Works offline

Load once, disconnect, keep converting. The network is only needed to fetch the page itself.
