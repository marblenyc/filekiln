PDF & Word Metadata Remover

See and remove hidden metadata from PDF and Word files - author, title, creation dates, editing software - entirely in your browser. The document never leaves your machine.

Private by construction. Your file is opened with JavaScript inside this page. It is never transmitted, and the tool keeps working with the network unplugged.

Every PDF and Word file carries a little dossier about itself: who wrote it (frequently a real account name), what company license produced it, which software and version, when it was created and every time it was touched since. Most people have sent a "clean" document that quietly named a colleague, a client, or a template path. The first thing this page does is show you that dossier - for your file, exactly as written. The second thing it does is remove it, in your browser: PDFs are blanked in place so the file stays byte-for-byte structurally valid, Word files get their properties parts swapped for empty ones with the document itself copied untouched.

One honest boundary, stated plainly on the page and in the FAQ: metadata removal is not redaction. This cleans the properties about the document; it does not touch text inside the document. And where a PDF stores its info dictionary somewhere in-place blanking can't reach, the tool says what it could not clear instead of pretending. Files that would need guessing are refused, not mangled.

Questions this tool gets asked

What metadata hides in a PDF or Word document?

More than people expect: the author's name (often a real login name), company, title, the software and version used, creation and modification dates, and sometimes template paths. This page shows you exactly what your file carries before anything is removed.

How does the removal work - is my document uploaded?

Never. The file is edited by JavaScript in your tab. For PDFs, the metadata values are blanked in place so the file structure stays byte-for-byte valid; for Word files, the document properties parts are replaced with empty ones. The cleaned file downloads straight from browser memory.

Does this also redact the document's contents?

No - and it is important to be clear about that. This tool removes the properties ABOUT the document (author, dates, software). Text inside the document, including anything under a black rectangle, is untouched. Never rely on drawn boxes for redaction.

What exactly is removed from a Word file?

The core properties (author, last modified by, title, dates, revision number), the app properties (software, company, editing time), and every value in the custom properties part. The document text, images, and formatting are copied over untouched.

Are there PDFs it can't fully clean?

Yes, and it tells you when. Encrypted PDFs are refused outright. Some PDFs store their info dictionary inside compressed object streams where in-place blanking can't reach - the tool reports what it found and what it could not clear, rather than claiming a clean it didn't do.

How do I just see what metadata a document carries, without changing it?

Drop it here and read the table - the values are shown before anything downloads, and your original file on disk is never modified (the clean copy is a separate download). Adobe Reader's File > Properties and Word's File > Info show some of the same fields, but not the XMP packet or custom properties this page surfaces.
